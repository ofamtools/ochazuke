    03Ownership
    Shared does not mean global.
    Shared state belongs to a Runtime instance. Each Input keeps its own editing state. A modal Frame is drawn above its parent and becomes the top Context for key routing, without replacing its parent. Terms: Frame, layer, full glossary.
    Choose the owner.
    The structs hold the boundary. These examples omit fields to show that boundary clearly.
    Interactive illustration · no backend connection
    Cover a page. Keep its state.
    Edit the base value, push a palette, then a picker. Pop both to recover the same page context and value. This illustrates retention, not picker execution. Each frame here is context plus state, not pixels; the page input keeps its own text.
    

    04Design notes
    Why these boundaries?
    Rationale below follows observable code structure and comments. Tradeoffs are consequences of the implementation, not promises of future behavior.
    One operation catalog.
    An Operation declares a verb, noun, parameters, result description, and handler. Bindings store Requests. The palette reads the catalog. The CLI sends the same Request shape.
    A command has one runtime dispatch path, but key interpretation still belongs to Model and the editor grammar. The socket invokes operations directly; it does not simulate a keypress.
    runtime.go · Operation, ExecuteAt
    Context resolves overrides.
    A Context is a layer path plus an optional InputID. EffectiveBindings walks ancestors to descendants, overlays complete key sequences, and applies mode-specific bindings after modeless bindings within each layer.
    ExecuteAt checks actions in the reverse direction. The closest layer action wins, then the registered operation runs. A targeted request resolves the target input's own path.
    runtime.go · EffectiveBindings, ExecuteAt
    Retain objects, switch context.
    OpenPage restores the page's exact Frame pointer. Push adds a modal frame; Pop removes only the top frame. The parent's input mode, text, cursor, history, and frame state stay in their existing owners.
    Open modals block page navigation. Retention is in memory, not persistence across application restarts. Reopening the picker creates fresh editor history; reopening the palette resets its drafts.
    pages.go · OpenPage · runtime.go · Push, Pop
    Immutable work, current results.
    The picker queues commands with a captured root or immutable entry slice plus query and filter. Workers return Tea messages. HandleMessage checks the picker identity, open state, and generation before applying a result.
    Cancellation reduces obsolete work; generation checks reject obsolete results. Indexing uses native Git ignore rules and has a two-minute context timeout. Missing Git or filesystem failures become visible picker errors.
    picker.go · queueSearch, HandleMessage · picker_search.go · indexPicker
    Undo stays with the field.
    Input stores text as runes and history as a tree with parent and child indices. A new edit after undo adds another child instead of destroying the old branch. Insert-mode sessions group their edits.
    Registers and yank history belong to Runtime, so text can move between inputs without sharing their undo trees. Yank retains character, line, or block shape. The history keeps at most 100 entries.
    input.go · Replace, Undo, Redo · registers.go · storeYank
    Replay dispatch, not time.
    Macros record application key events, including paste metadata, into registers. Replay uses Model.dispatchKey, so it sees the same palette, modal, layer, and editor routing as live keys.
    Replay is synchronous. It does not wait for asynchronous picker indexing or search. A selection command can fail while loading. Replay limits depth to 16 and total dispatched steps to 10,000; failure can close added frames, but does not roll back prior text edits.
    macros.go · replayMacro · model.go · dispatchKey
    Read the boundaries and limitations before extending the app
    • Runtime is event-loop-owned, not a thread-safe shared service. Server goroutines send CallMsg to the Tea program.
    • The socket is local Unix-domain transport. Its parent directory must be current-user-owned and private, and the socket uses mode 0600. It is not an HTTP or network API.
    • Transport replies marshal and unmarshal the result before replying, detaching live maps and slices. The default client and server deadlines are 10 seconds.
    • Model owns viewports, dimensions, status and rendering adapters. Runtime owns registered page frames and editing state; domain and UI ownership are separate, not separate processes.
    • Picker selection checks that the originating Input object, text, and kind are unchanged before replacing the captured range. Cancellation leaves the origin untouched.
    • Frame.State is a map of component-owned values. There is no static schema for every modal's state. Render callbacks are Go functions, not serializable page descriptions.
    • Text offsets are rune indices. Rendering and block selection also use terminal cell widths and grapheme helpers. Rune offsets and display columns are not interchangeable.
    • This guide is a source snapshot. Relative source links open repository files; line ranges are evidence labels and may shift as code changes.

    Regenerate the catalogs after source changes
    From the repository root, run go run ./cmd/docgen. It rewrites docs/actions.html, docs/bindings.html, docs/api.html and docs/transport.html from a fresh NewDemo() and the root package's exported declarations. Keep all four files beside architecture.html when copying the guide. The checked-in pages are browsable offline; they do not query a running app.
    For terminal documentation, use go doc -all . or go doc Runtime.Execute. For the live operation registry, use go run ./cmd/ochazuke operations list while the app is running.
