Default bindings 51

Every registered layer binding in the demo, including palette, picker and yank-history layers. These are declarations, not a flattened effective keymap: descendant layers override ancestors; mode-specific bindings override modeless bindings within a layer. Only layers on the current context path participate.

The editor's Vim/Readline grammar and macro prefixes are separate from Layer.Bindings. See the editor keyboard guide and palette and selector controls for those keys. ctrl+@ is Bubble Tea's spelling for Ctrl-Space. The palette and unfinished editor grammar can handle keys before binding lookup.
