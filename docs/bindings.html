02 / Registered noun rows

Default bindings 681

Every mode-table row of every noun in the demo, including the editor noun's Readline and Vim tables, its pending modes, and the palette, picker, yank-history and modal nouns. This table lists noun declarations only: it omits per-instance binding rows and is not a flattened effective keymap. Keys can also depend on guards and operation availability. The shared resolver drives live key dispatch, macro playback and effective binding/help listings.

Resolution first considers capture rows (Binding.Capture, configured as capture) outer-first, app first and the editor fallback last; the first answering level wins. A passthrough base mode skips capture. Ordinary rows then bubble from the focused instance (or its inner completion level) outward to app. An open modal cuts off the instances beneath it and inserts the modal noun before app. The editor noun is a fallback only when an input is on the path; for a focused read-only input it answers immediately after that input instead.

At each level, instance rows for the active mode (plus unqualified instance rows outside a pending mode) precede noun mode rows (including declared mode inheritance), followed by the noun's any-base-mode rows. Exact keys rank ahead of key classes (<digit>, <alpha>, <printable>, <paste>), then <any>; table order breaks ties. A pending mode excludes any-base-mode rows. During bubbling, an available longer sequence anywhere on the remaining walk can make the resolver wait, keeping the innermost exact match as fallback; an answering key class ends that scan. ctrl+space is Bubble Tea v2's spelling for Ctrl-Space.
