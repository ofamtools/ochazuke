Default bindings 417

Every mode-table row of every noun in the demo, including the editor noun's Readline and Vim tables, its pending modes, and the palette, picker, yank-history and modal nouns. These are declarations, not a flattened effective keymap: the resolver walks the focused instance outward to app, then the editor noun as the fallback; at each level the mode table is read before the any-mode table; exact keys beat key classes (<digit>, <alpha>, <printable>, <paste>) beat <any>. A pending mode reads only its own table. ctrl+space is Bubble Tea v2's spelling for Ctrl-Space.
