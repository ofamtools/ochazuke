Default bindings 61

Every registered layer binding in the demo, including palette, picker and yank-history layers. These are declarations, not a flattened effective keymap: descendant layers override ancestors; mode-specific bindings override modeless bindings within a layer. Only layers on the current context path participate.

The editor's Vim/Readline grammar and macro prefixes are separate from Layer.Bindings. See the editor keyboard guide and palette and selector controls for those keys. ctrl+@ is Bubble Tea's spelling for Ctrl-Space. The palette and unfinished editor grammar can handle keys before binding lookup.

04 / One request contract

CLI & socket API

There is no HTTP API. The CLI sends one JSON request per Unix-socket connection. The runtime processes it on the UI loop. Use the action catalog above for operation names and parameter schemas.

// Simplified JavaScript-shaped request; the wire format is JSON.
{
  verb: "undo",
  noun: "input",
  target: "focused-input",
  args: { steps: 1 }
}

With an application running, query its actual registry or invoke an action:

go run ./cmd/ochazuke operations list
go run ./cmd/ochazuke input undo --json '{"steps":1}'

Request and Response in the Go catalog describe the wire envelopes; Call, Listen and CallMsg provide transport integration. The socket uses a private current-user-owned directory, mode 0600, ten-second deadlines and a 1 MiB scanner limit. See live CLI setup for socket selection.
