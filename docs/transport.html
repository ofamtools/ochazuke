04 / One request contract

CLI & socket API

There is no HTTP API. The CLI sends one JSON request per Unix-socket connection. The runtime processes it on the UI loop. Use the action catalog for operation names and parameter schemas.

// Simplified JavaScript-shaped request; the wire format is JSON.
{
  verb: "undo",
  noun: "input",
  target: "focused-input",
  args: { steps: 1 }
}

With an application running, query its actual registry or invoke an action:

go run ./cmd/ochazuke operations list
go run ./cmd/ochazuke input undo --json '{"steps":1}'

Request and Response in the Go API catalog describe the wire envelopes; Call, Listen and CallMsg provide transport integration. The socket uses a private current-user-owned directory, mode 0600, ten-second deadlines and a 1 MiB scanner limit. See live CLI setup for socket selection.
